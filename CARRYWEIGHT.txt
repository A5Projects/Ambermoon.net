Temporary carry capacity and save transfer

Enable the existing cheat console in Options -> Settings -> Enable cheats.

  carryweight 1000   Add 1000 kg of capacity to every companion.
  carryweight 0      Remove the bonus; use this build's normal capacity.
  carryweight        Show the current bonus.
  help carryweight   Show command help.

The number sets the total extra capacity, rather than adding it again each
time. Whole numbers from 0 to 10000 are accepted. The bonus lasts until the
application is restarted and survives loading another save during that session.
It applies to active and unrecruited companions. It changes neither strength
nor item/gold weight, inventory slots, combat stats or the save format.
Re-enter it after restarting if the party still needs the extra capacity.

Save transfer between Immersive Edition and Expanded

Ambermoon Immersive Edition and Ambermoon Expanded use the same bundled game
data and save format. Select the same edition and language when transferring
saves; the tested pair is German Advanced. This does not imply compatibility
between Original and Advanced, or arbitrary other data releases/mods.

Earned stats, points, spells and world progress are retained. Future gains and
costs use the destination build's rules. Both builds now recalculate carried
weight for every stored companion on load. This also covers companions who
join later: the old default build repaired only active members, which could
make a lighter imported cached weight underflow when gold was removed.

The carry bonus itself is not saved. In particular, saving with the bonus on
does not change the character's strength or give permanent carrying capacity
to another build. The destination must enable its own bonus if needed.
Ordinary overloading under its different capacity/weight rules is expected.

Save transfer with upstream Ambermoon.net 1.16.0

Use the same edition and language on both sides. For example, German Original
uses Saves/german and German Advanced uses Saves/advanced_german. A whole
edition folder includes the Save.XX directories and the Saves and Saves.cfg
slot indexes. Copy it into a fresh destination to retain the slot names and
Continue selection. For slots above 10, enable additional slots on the
receiving installation. An F7 quicksave loads through its normal slot.
Round-trip checks covered German Original, German Advanced and English
Advanced saves, including an F7 save in slot 30.

This local Immersive build uses the same saved quest and item-acquisition
flags as upstream 1.16.0. Both remember obtaining the Map of Lyramion and the
Rune Alphabet. Old saves recover the map from its quest flag or the item and
recover the alphabet if a stored companion still has it.

Older builds used one bit for two events. Following upstream's migration,
that legacy bit counts as finding the yellow sphere. An old save has no way
to distinguish it from Valdyn's conversation with Sheera. New saves keep the
two events independently.

New saves record inventory weight using upstream's five grams per gold coin
for every companion. Immersive recalculates the weight used during play when
loading. To transfer an older Immersive Advanced save, load it here and save
to a new slot first. Characters can still be overloaded under upstream rules.

Original balance in Immersive UI v1.0.1 and later

The Original game-data selection now uses original capacity (1 kg per effective
strength point) and gold weight (5 g per coin). Advanced in Immersive Edition v1.1.0 uses 2 kg per strength
point and 1 g per coin. The normal 999-gram allowance applies in either case. Advanced previously used
4 kg through v1.0.2; upgrading can leave heavily loaded characters overloaded.
No items are removed. Use the temporary carryweight command to reach storage.
Older Original saves from Immersive UI v1.0.0 still load, with gold weight corrected
for every companion. The party may be overloaded after returning to original
limits. Use carryweight temporarily if needed to reach storage; progress and the
save format are unchanged. This change is included in v1.0.1; the earlier
v1.0.0 download is unchanged.
